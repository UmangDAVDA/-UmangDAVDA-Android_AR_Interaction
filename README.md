Android_AR_Interaction

-Startbtn.cs This script is attached to working btn object for button click function connection and disconnection

-Working.cs Its for connection i.e to connect Male manifold and Female coupling sections and to rotate and engage

-Workingd.cs Its for disconnection i.e to to rotate and disengage and to disconnect Male manifold and Female coupling sections.

-form.cs This is the User Login form script which takes Name and Number and submits it to output using Login button

-restart.cs To restart application

-Quit.cs To quit application
